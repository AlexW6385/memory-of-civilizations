# 文明的记忆

[English](README.md)

一颗可以行走、可以飞越的小星球。地球上的各个文明在它们原本的位置上，每一个都是某个地方的某个时代。每个**聚落**都是写实、细节丰富的 3D 城镇：中心是一座依照真实建筑建造的著名地标，带有室内；周围是那个民族和时代的城镇风貌，有街巷、民居、集市、园林、城墙、水系和劳作的人。材料、光影和天气都尽量真实，音乐也按各自文明的风格来写。

**进入：<https://alexw6385.github.io/memory-of-civilizations/>**。电脑和手机都可以，浏览器需要支持 WebGPU（Chrome、Edge、Safari 26）。界面可在中英文之间切换。

名字的意思只有一层：这些建筑是各个文明的记忆。这里是一个用来行走的世界，不是学习工具：没有笔记、没有标记、没有路线。

> **网站现状（v12.0，2026-11-12）：** 计划中的 94 个聚落全部建成并立在星球上，每个都依据有出处的资料档案建造，并已在作者的 Chrome 中逐一检查过到达时的第一眼。下一步：到达点之外的深度，以及手机。详见 [DESIGN.md](DESIGN.md) §10。

星球是一个半径 12 公里的球体，大陆和纬度与地球一致。每个聚落都在它真实位置附近，聚落密集的地区略作放大。聚落之间有原野、道路、河流和大海。整颗星球只有一个太阳，所以可能这座城是正午，另一座城已是傍晚。天气和季节随地区变化。飞得越高，越能看到地面弯下去。布局说明见 [docs/world.md](docs/world.md)。

## 操作

| 电脑 | |
|---|---|
| W A S D / 方向键 | 行走 |
| 鼠标（双击捕获） | 环顾 |
| Q / E | 转身 |
| Shift | 奔跑 |
| 按住空格 | 飞行，按得越久越快；松开后滑翔落到地面或屋顶 |
| 连按两次空格 | 巡航 |
| M | 地球仪地图：拖动旋转，滚轮缩放，点击城市前往 |
| R | 随机去一座城市 |
| T | 游览：依次在每座城市上空绕飞一圈，每座约一分钟。按 R 跳到下一座，任何其他操作都会让你停在当前位置 |
| Esc | 关闭面板，释放鼠标 |

首次访问会显示一条简短的操作提示（可用按钮关闭，之后不再出现）。从任一门洞都能走进去：每个到达点附近的普通建筑都可以进入。

手机上：左手拇指推摇杆行走，拖动屏幕环顾，按住 ↑ 飞行。点角落的小地图打开地球仪，上面有"随机城市"和"游览"按钮。角落卡片上的滑块可以调整时间。

## 怎么做的

- **先写档案。** 每个聚落都依据 [`docs/settlements/`](docs/settlements) 里有出处的资料档案建造，档案分地标（平面、尺寸、结构、材料、装饰、光线）、城镇风貌和声音三部分。资料明确记载的和推断的内容分开标注。
- **平面是数据，外观是代码。** 聚落以米为单位，定义墙、门窗、地面、屋顶、柱子和器物（`src/settlements/<id>/`、`src/buildings/`），由各文明可复用的建筑语汇绘制（`src/styles/<style>/`）。街头生活、集市和日常器物来自 `src/objects/`。
- **渲染：** three.js WebGPU，使用反向深度缓冲。材质是程序化的 PBR，纹理顺着每面墙的砌筑方向排列。阴影用级联阴影加缓存，另有 GTAO、泛光、AgX 色调映射和人眼适应。室内有空气感、光柱和彩色玻璃透光，夜里有灯火。
- **烘焙光照：** 每处室内的间接光都离线光线追踪进辐照度体（`tools/bake.mjs` → `data/gi/`）。
- **性能：** 每个聚落的静态网格合并，再分格并配粗略的细节层级。另有动态分辨率和自动画质。随机顺序里的下一座城会提前预加载，所以跳转几乎是即时的。
- **星球：** 球面地形在 worker 中流式生成，有生物群系、海洋和大气。树木和草地用实例化绘制，带风动和细节层级（`src/planet/`、`src/engine/flora/`）。
- **声音：** 每个聚落的音乐和环境声都在浏览器里实时合成，不同房间有各自的混响。

全部是纯静态 ES 模块，没有构建步骤，也不需要服务器。three.js 放在 `src/vendor/` 里。

## 开发

```bash
npm install                        # 仅开发工具
npm run serve                      # http://127.0.0.1:8000
npm run check                      # 平面检查：可行走、房间可达、无悬空
npm run walk -- --sites            # 检查每个聚落的行走路线
node tools/disc-check.mjs          # 平面在圆盘内、材质已知、房间有音乐
node tools/view-check.mjs          # 每座地标有一个自由的到达视角
node tools/rim-check.mjs           # 每个聚落边缘与原野的衔接
node tools/geo-budget.mjs          # 每个聚落的几何预算
npm run bake -- giza               # 烘焙间接光到 data/gi/
npm run shot -- --building parthenon    # 固定机位截图 → shots/
npm run budget                     # 加载与体积预算
npm test
```

URL 参数：`?perf` 显示帧时间面板（带开关，对应 `window.palace.perf`）；`?trace` 统计编译的管线；`?bench` 在作者的机器上跑固定路线，报告帧率、绘制调用和卡顿；`?capture` 以固定的 1/30 秒步长运行，用于录屏；`?tour=a,b,c` 固定游览顺序；`?quality=high|medium|low|cinema` 指定画质（默认自动）。

每次推送到 `master` 都会运行检查，并把网站发布到 GitHub Pages。多 agent 并行开发的做法见 [docs/parallel-work.md](docs/parallel-work.md)。
