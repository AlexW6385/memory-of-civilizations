# 文明的记忆

[English](README.md)

一颗可以行走、可以飞越的小星球：地球上的各个文明——每一个都是“某地的某个时代”——各在其位，以写实而细节丰富的 3D **聚落**呈现：一座依照真实建筑建造、带完整室内的著名地标，以及环绕它的、属于那个民族和时代的城镇风貌——街巷、民居、集市、园林、城墙、水系和日常器物——有真实的材料、光与影，以及符合其文明的音乐。

**进入：<https://alexw6385.github.io/memory-of-civilizations/>** —— 电脑或手机，需要支持 WebGPU 的浏览器（Chrome、Edge、Safari 26）。界面可切换中文与英文。

名字的意思只有一层：这些建筑是各个文明的记忆。这里是一个用来行走的世界，不是学习工具：没有笔记、没有标记、没有路线。

> **网站现状（v8.0，2026-11-03）：** 小星球已经建成，地球的大陆和上一版的十座地标都在上面，各自成为一个聚落。清单上其余四十多个文明（[DESIGN.md](DESIGN.md) §7）接下来陆续加入。

## 现在可以参观

- **埃德富荷鲁斯神庙**（托勒密埃及，前237—前57年），古埃及保存最完整的神庙，按真实尺度建造：带旗杆与花岗岩荷鲁斯隼像的塔门、三面 32 根柱子的庭院、18 根柱子的前厅、显现大厅、供奉厅、九神厅、安放内克塔内布二世花岗岩神龛与圣船的至圣所、秘仪回廊及其九座小堂、围墙内的外回廊——每进一厅，地面更高、屋顶更低、光线更暗。四周是它所在城镇的泥砖房屋与棕榈。

- **帕特农神庙**（雅典，前447—前432年），立于卫城岩丘之上：完整的多立克柱式、山花、环绕金象牙雅典娜像的双层柱廊与像前水池，以及有四根爱奥尼柱的后殿宝库。
- **万神殿**（罗马，约公元114—128年）：十六根花岗岩柱的门廊、青铜大门、彩色大理石的圆厅，以及其上的藻井穹顶与敞开的天眼。
- **圆顶清真寺（岩石圆顶）**（耶路撒冷，691/692年）：岩石上方的金色穹顶，大理石与马赛克的八角形外墙，两圈回廊与镀金拱廊；立于高台之上，旁有锁链圆顶，四周是山坡上的橄榄树与带小圆顶的石屋。
- **巴黎圣礼拜堂**（1242—1248年）：彩绘柱子的下层礼拜堂，以及其上的上层礼拜堂——十五扇彩色玻璃窗围成的“玻璃笼”，蓝底金星的拱顶，彩色阳光洒落在地面上；周围是木骨架房屋与果园。
- **佛光寺东大殿**（五台山，857年）：现存最宏伟的唐代木构，登三层台地而上，硕大的斗栱与深远的出檐托起庑殿顶，殿内佛坛上诸佛隐在半明半暗中。
- **平等院凤凰堂**（宇治，1053年）：隔池相望的阿弥陀净土之殿，中堂屋脊上立着一对金铜凤凰，两翼回廊折向池边的角楼；过拱桥、入殿门，可见天盖下金色的阿弥陀佛。四周是赤松、红叶与竹林。
- **桑吉大塔**（公元前1世纪—公元1世纪）：山顶上白色的覆钵，可在石栏与基台之间、再登上台顶绕塔而行；四座雕刻的塔门立于四方，旁有阿育王的狮子石柱。
- **孔克圣福瓦修道院教堂**（约1050—1120年），通往圣地亚哥朝圣路上的教堂：从雕刻着最后审判的西门楣下进入，筒形拱顶下高而幽暗的中殿夹在两层廊台之间，走到被采光塔照亮的十字交叉处，再沿回廊绕过三座放射状小礼拜堂；南侧回廊院中央是绿色蛇纹石水盆。四周是山坡上片岩墙、石板顶的民居。
- **圣索菲亚大教堂**（君士坦丁堡，532—537年，穹顶562年重建）：架在帆拱上、底部环绕四十扇窗的大穹顶，半穹顶与半圆殿，楼廊，金色马赛克与大理石，圣坛与读经台，内外前廊与中庭——立于山丘之上，四周是瓦顶房屋。

它们立在**一颗小星球**上：半径 8 公里的球面，照着地球的大陆轮廓与纬度，每个文明在它真实位置附近（拥挤的地区略微放大），之间是开阔的原野——海岸、丘陵、山脉、沙漠、森林、雪原——和大海。一个太阳：在桑吉高悬，在巴黎低斜，宇治已是傍晚，雅典还是午后。飞上高空，地面在脚下弯成球面。布局说明见 [docs/world.md](docs/world.md)。

## 操作

W A S D 或方向键行走，鼠标环顾（点击画面锁定鼠标），Shift 奔跑，**按住空格飞行**（松开即缓缓降落——落到地面或屋顶上），M 打开地球仪，Esc 暂停。手机上：左手拇指拖动摇杆行走，在其他地方拖动环顾，按住箭头按钮飞行。加载完成后世界会自动打开，点击画面开始环顾。左上角是小地图（点击打开大地图，可隐藏）、时钟（拖动选择时刻，或暂停/继续昼夜流转），以及当前的移动状态：步行、奔跑或飞行，速度与高度。飞得越高越快。地球仪（M，或点击小地图）：拖动转动，滚轮拉近；点击一个聚落前往它的地标，点击陆地上任意一点前往那里。

## 如何制作

- **先写考据档案。** 每座建筑都依据 [`docs/buildings/`](docs/buildings)（将迁至 `docs/settlements/`，并增加城镇风貌部分）中有出处的档案建造（真实实例、平面与尺寸、结构、用途、材料、装饰、采光、音乐；并区分来源明确记载的内容与我们的推断）。世界布局见 [`docs/world.md`](docs/world.md)。
- **平面是数据，外观是代码。** 建筑的平面以米为单位，由墙、门洞、地面、屋顶、柱子与物件组成（`src/buildings/<id>/plan.js`），再由该文明可复用的建筑语汇绘制（`src/styles/<文明>/`：柱与柱头、圆凸线脚与凹弧檐口、塔门、门框、雕像）。
- **渲染：** three.js WebGPU（无 WebGPU 时退回 WebGL 2），与每面墙真实砌层对齐的程序化 PBR 材质，级联阴影，GTAO，泛光，AgX 色调映射，以及人眼明暗适应。
- **烘焙光照：** 间接光（天空、石面反射的阳光、油灯）离线光线追踪成每座建筑的辐照度体积（`tools/bake.mjs` → `data/gi/`），随建筑一起加载。
- **世界：** v7.1——城市由一个高度函数描述，地形分块按距离细化，在 Worker 中生成，民居排布在同一套街坊网格上（`src/world/`）；v8.0——小星球（`src/planet/`：球面、大陆、生物群系、海洋、大气、按纬度的太阳），以及每个聚落各自设计的城镇风貌。树木与草实例化绘制，带细节层级并随风摇动（`src/engine/flora/`）。
- **音乐：** 依据每座建筑的乐谱在浏览器中实时合成（`src/buildings/<id>/music.js`），从露天庭院走进大厅、再到至圣所，音乐随之变化。

纯静态 ES 模块，没有构建步骤，也没有服务器；three.js 从 CDN 加载。

## 开发

```bash
npm install                      # 仅开发工具：playwright、three、three-mesh-bvh
npm run serve                    # http://127.0.0.1:8000
npm run check                    # 平面检查：可行走性、每个房间可达、门洞连通、无悬空物件
npm run bake -- edfu             # 烘焙建筑的间接光 → data/gi/edfu.bin
npm run shot -- --building edfu  # 在 tools/viewpoints.json 的固定视点截图 → shots/
npm run budget                   # 加载与体积预算
npm test
```

每次推送到 `master` 都会运行检查并发布到 GitHub Pages。
